# قالب WordPress

در این پوشه، قالب اختصاصی `vetoapp-landing` ساخته می‌شود.

قالب باید RTL، سبک، سازگار با ویرایشگر بلوکی WordPress و مبتنی بر راهنمای `../design/brand-guide.md` باشد. در مرحلهٔ اول شامل header، footer، صفحهٔ اصلی، صفحهٔ دانلود، صفحهٔ حریم خصوصی، قوانین استفاده و تماس با ما خواهد بود.
