# کنترل کیفیت ظاهری قالب

این پوشه خروجی کنترل ظاهری قالب `VetoApp Landing` را نگه می‌دارد:

- `landing-desktop.png` — viewport دسکتاپ 1440×1050
- `landing-mobile.png` — viewport موبایل 390×844

هر دو تصویر با HTML و CSS واقعی قالب و با مرورگر headless محلی تولید شده‌اند. آن‌ها برای بررسی چیدمان، RTL، منوی واکنش‌گرا، CTAها و دارایی‌های برند هستند و دادهٔ زندهٔ سامانه را نشان نمی‌دهند.

علاوه بر این کنترل ظاهری، مسیر WordPress واقعی با MariaDB جدا، PHP-FPM، فعال‌سازی قالب و Nginx در یک محیط Docker موقت آزموده شده است.
