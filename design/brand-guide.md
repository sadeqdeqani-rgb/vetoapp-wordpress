# راهنمای هویت بصری لندینگ VetoApp

## مبنا

طراحی WordPress باید با رابط Flutter فعلی یکپارچه باشد، اما برای وب سبک، خوانا و mobile-first بماند.

## اجزای رابط

- شعاع کارت‌ها: `24px`
- شعاع input و button: `16px`
- دکمهٔ اصلی: سرمه‌ای با متن سفید
- دکمهٔ ثانویه: border سرمه‌ای، پس‌زمینهٔ سفید
- سایهٔ کارت‌ها: کم‌رنگ و محدود؛ نه افکت‌های سنگین
- جهت تمام صفحات عمومی: RTL

## تایپوگرافی

رابط Flutter فعلی از `B Mitra` استفاده می‌کند. پیش از embed کردن این فونت در وب باید وضعیت مجوز وب‌فونت آن بررسی شود. در صورت نبود مجوز مناسب، یک فونت فارسی آزاد و نزدیک از نظر خوانایی انتخاب می‌شود.

## تصویر و رسانه

- لوگو و سه SVG آمادهٔ محیط سامانه از دارایی‌های VetoApp استفاده شوند.
- تصاویر باید responsive و بهینه باشند.
- ویدئو یا فایل رسانه‌ای حجیم روی VPS نگه‌داری نشود؛ در صورت نیاز از سرویس ویدئو یا CDN جدا استفاده می‌شود.

## قالب پیشنهادی

یک Block Theme اختصاصی و سبک با نام موقت `vetoapp-landing` ساخته می‌شود. صفحه‌سازهای سنگین و مجموعه‌های افزونهٔ غیرضروری استفاده نمی‌شوند.
